# 🐱 Spinning Cat - 旋转猫猫

一个模仿 [spinning.cat](https://spinning.cat/) 的互动网页应用，让你的猫猫疯狂旋转！

## ✨ 功能特性

### 🎮 核心功能
- **旋转控制**: 按住 "SPIN!" 按钮让猫猫旋转
- **速度显示**: 实时显示当前旋转速度 (RPM)
- **旋转计数**: 记录本次会话和历史总旋转次数
- **最高速度**: 追踪并显示你达到的最高速度

### 🎨 主题系统
- **浅色主题**: 清新明亮的界面
- **深色主题**: 护眼的暗色调
- **彩虹主题**: 炫酷的彩虹特效

### 🎉 特殊模式
- **狂欢模式**: 开启炫彩粒子效果和颜色变换
- **加速模式**: 提升旋转加速度和最大速度
- **音效模式**: 添加旋转音效（可扩展）

### 🎵 音乐混音
- 多种音乐混音选择
- 经典版、电子版、爵士版、摇滚版

### 📊 统计系统
- 本次旋转次数
- 历史总旋转次数
- 最高速度记录
- 里程碑庆祝（每 10 次旋转）

### 🌍 其他功能
- 多语言支持（中文、英文、日文）
- 在线用户数显示
- 终端日志系统
- 排行榜显示
- 响应式设计，支持移动端

## ⌨️ 快捷键

- `空格键` - 开始/停止旋转
- `P` - 切换狂欢模式
- `T` - 切换加速模式
- `S` - 切换音效

## 🎁 彩蛋

连续点击页面左上角的 Logo 10 次，触发超级狂欢模式！

## 🚀 使用方法

1. 克隆或下载此仓库
2. 在浏览器中打开 `index.html`
3. 点击并按住 "SPIN!" 按钮
4. 享受旋转的乐趣！

## 🐛 调试命令

打开浏览器控制台，可以使用以下命令：

```javascript
// 查看游戏状态
window.spinningCat.getState()

// 重置统计数据
window.spinningCat.resetStats()

// 添加旋转次数（测试用）
window.spinningCat.addSpins(100)
```
